In Node.js, streaming means processing data piece by piece instead of loading the whole file or data into memory at once.

Example
Instead of waiting for a full file to download before using it, a stream sends chunks continuously.

Why it is useful
handles large files efficiently
reduces memory usage
works well for reading/writing files, network data, and real-time data
Types of streams
Readable stream: reads data
Writable stream: writes

In simple words
Streaming means:
“Don’t wait for everything; process data as it arrives.”
